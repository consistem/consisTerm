FindersKeepers
==============

A pixel recreation of Apple's Geneva 9 by Giles Booth (@blogmywiki), made
with BitFontMaker2.

Licence: Creative Commons Attribution, as stated on the font's page.
  https://www.pentacom.jp/pentacom/bitfontmaker2/gallery/?id=3809
  https://creativecommons.org/licenses/by/4.0/

The TTF is the one system.css (sakofchit/system.css, MIT) ships in its npm
package (@sakun/system.css 0.1.11, dist/FindersKeepers.ttf), with the accented
letters it lacked added - see MODIFIED.txt.
system.css names it `Geneva_9`.

It is drawn on a 64-unit pixel grid at 1024 units to the em: one font pixel
is one screen pixel at 16 px, which is the size the skin sets it at.

Attribution: "FindersKeepers" by Giles Booth, CC BY.
