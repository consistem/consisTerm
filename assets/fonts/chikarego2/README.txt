ChiKareGo2
==========

A pixel recreation of Apple's Chicago 12 by Giles Booth (@blogmywiki),
made with BitFontMaker2.

Licence: Creative Commons Attribution (as stated on the font's page:
"license : (Creative Commons Attribution)").
  https://www.pentacom.jp/pentacom/bitfontmaker2/gallery/?id=3780
  https://creativecommons.org/licenses/by/4.0/

The TTF is the one system.css (sakofchit/system.css, MIT) ships in its npm
package (@sakun/system.css 0.1.11, dist/ChiKareGo2.ttf, identical to
dist/Chicago_12.ttf), with the accented letters it lacked added - see
MODIFIED.txt. system.css names it `Chicago_12` and sets
its buttons, fields, menus and title bars in it.

It is drawn on a 64-unit pixel grid at 1024 units to the em: one font pixel
is one screen pixel at 16 px, which is the size the skin sets it at.

Attribution: "ChiKareGo2" by Giles Booth, CC BY.
