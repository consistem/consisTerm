Press Start 2P
==============

The pixel face snes.css (devMiguelCarrero/snes.css, MIT) sets every control
and label in (`$main-font: 'Press Start 2P'`), by CodeMan38 (cody@zone38.net).
From Google Fonts (google/fonts, ofl/pressstart2p), with a line gap added
and, as the OFL requires of a modified face, renamed "SNES Pixel 8px" - see
MODIFIED.txt.

Licence: SIL Open Font License 1.1 - see OFL.txt beside this file.

It is drawn on an 8 px grid: one font pixel is one screen pixel at 8 px,
which is the size the skin sets it at. It covers Latin-1 itself, so no
accents had to be added.
